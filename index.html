RamanInstant Guide

Protocol & Technical Specifications

01. Baseline Correction

We use the SNIP algorithm (Statistics-sensitive Non-linear Iterative Peak-clipping) to estimate the background signal (fluorescence, etc.) without distorting Raman peaks.

Iterations: More iterations remove more background. Use the slider in the sidebar to fine-tune the removal depth for your specific sample.

02. Data Requirements

For high-fidelity analysis, please ensure your files meet these standards:

  • Format: .csv, .txt, or .asc (UTF-8).
  • Columns: Column 1 = Raman Shift (cm⁻¹), Column 2 = Intensity.
  • Cleanliness: The parser handles most headers, but raw 2-column data is preferred.

03. Peak Analysis

Center positions are calculated using parabolic interpolation of the highest 3 points for sub-pixel precision. FWHM is calculated directly from the half-maximum threshold.

Note on Overlaps: If peaks are blended (e.g., D and G bands in carbon), the software reports the envelope centroid. Use specialized fitting for deconvolution.

04. Collective Analysis

Select multiple files using the COMP button, then use the Statistical Average tool to generate a mean trace with shaded standard deviation bands.
