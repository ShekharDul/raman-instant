Instant Raman Guide

Protocol & Technical Specifications

01. Universal File Ingest

Instant Raman features an intelligent ingest engine that automatically detects and normalizes professional spectral formats, ensuring you can drop files directly from your spectrometer.

  • JCAMP-DX: .dx and .jdx standards.
  • Bruker: .dpt native exports.
  • Horiba: LabSpec .xml and .txt exports.
  • Generic: Column-based CSV, TXT, and ASC.

02. Baseline Correction

We use the SNIP algorithm (Statistics-sensitive Non-linear Iterative Peak-clipping) to estimate the background signal (fluorescence, etc.) without distorting Raman peaks.

Iterations: More iterations remove more background. Use the slider in the sidebar to fine-tune the removal depth for your specific sample.

03. Peak Analysis & Metrology

Center positions are calculated using parabolic interpolation for sub-pixel precision. Use the Si Calibration Check tool to verify instrument accuracy against the standard 520.7 cm⁻¹ Silicon peak.

Note on Overlaps: If peaks are blended (e.g., D and G bands in carbon), the software reports the envelope centroid. Use specialized fitting for deconvolution.

04. Collective Analysis

Select multiple files using the COMP button, then use the Statistical Average tool to generate a mean trace with shaded standard deviation bands.

05. Advanced Deconvolution STAGING

We are currently finalizing the integration of a Levenberg-Marquardt (LM) non-linear fitting engine. This will enable simultaneous multi-peak optimization using Lorentzian and Gaussian profiles, providing rigorous standard errors and residual analysis for complex spectral regions.

06. Visual Accessibility

Our plotting engine utilizes high-contrast, color-blind safe palettes (Paul Tol muted schemes) to ensure that overlapping spectral traces remain distinguishable for all researchers. This supports inclusive collaboration and ensures figures are ready for high-fidelity scientific publication.
