Instant Raman Guide

Protocol & Technical Specifications

01. About the App

Instant Raman is a fast, simple tool built to help researchers process Raman spectroscopy data. It handles the heavy lifting of baseline correction and data visualization right in your browser, so you can focus on your results.

02. Baseline Correction

We use a method called the SNIP algorithm (Statistics-sensitive Non-linear Iterative Peak-clipping) to clean up your spectral data.

How it works

Automatic mode estimates the baseline using iterative clipping (SNIP). Manual mode interpolates between your selected anchors. Compare the corrected spectrum with the original data: baseline choices can affect peak heights and areas.

After baseline subtraction, negative corrected intensities are set to zero. A centered nine-point moving average smooths the result; the four points at each edge retain their corrected values. Normalisation follows smoothing. Automatic detection uses a 2% threshold of maximum processed intensity, merges candidates within 2.5 cm⁻¹, and retains up to 50 peaks.

Iterations: You can use the slider in the sidebar to adjust how much background to remove. More iterations generally mean a smoother, deeper baseline removal.

03. Preparing Your Data

To get the best results, make sure your files follow these simple rules:

Supported Formats

  • Spectral data: .csv, .xlsx, .xls.
  • CSV supports comma, semicolon, tab, or pipe separators, quoted fields, UTF-8, and UTF-16 with a byte-order mark.
  • Protocol files (.irp / .json) use a separate import flow.

Layout

The import preview suggests headings such as Raman Shift, Wavenumber, Intensity, and Counts. Check the worksheet, heading row, first data row, X column, and one or more intensity columns. Headerless files require manual column and unit selection. Each selected intensity column becomes a separate spectrum sharing the selected X column.

Choose Raman shift (cm⁻¹) or wavelength (nm). Wavelength conversion requires the measurement's laser wavelength. The app never infers units from numeric ranges. Set the decimal separator explicitly when necessary; remove thousands separators before importing.

The preview reports invalid rows and duplicate X values. Zero and negative intensities are retained in raw data. Excel includes hidden and filtered rows and uses saved formula results without recalculating them. At least three distinct numeric X values are required per spectrum. Select a worksheet per import; import the workbook again to choose another sheet.

04. How to Use

Step 1: Upload

Simply click the upload box or drag your files onto the screen. You can upload multiple files at once to compare them.

Step 2: Adjust

  • Auto Mode: Use the slider to let the app automatically find the baseline.
  • Manual Mode: Click directly on the graph to place your own baseline points if you need more control.

Step 3: Compare & View

Use the Layout menu to switch between seeing a single plot, stacking them (Waterfall), or viewing them in a grid.

05. Saving Your Work

When you’re happy with the results, you can download your data in several ways:

  • Analytical Excel: A clean spreadsheet containing your raw data, the calculated baseline, and the final corrected data.
  • Publication Figure: High-resolution PNG or Vector SVG graphs. When in Peak Fitting mode, the exporter automatically generates a professional dual-pane figure containing both the cumulative fit and the residual analysis.
  • Interactive Analytical Report: A self-contained "HTML Capsule" for seamless collaboration. This report includes high-fidelity interactive plots, complete peak parameter tables, replicate statistics (if applicable), and full metadata transparency.

06. Analytical Reporting

Beyond static images, Instant Raman generates a Self-Contained Analytical Report. This "HTML Capsule" embeds the raw data, processing settings, and high-fidelity interactive visualizations (including Deconvolution and Replicate Stats) into a single, shareable file. It requires no external dependencies or specialized software to view, making it ideal for sharing findings with collaborators or attaching to lab notebooks.

07. Cosmic Ray Rejection

Sensitive CCD detectors used in Raman spectrometers are susceptible to high-energy cosmic rays, which appear as sharp, unphysical spikes in your data. Instant Raman implements a non-destructive Z-score sliding window algorithm using Median Absolute Deviation (MAD).

Spike replacement: Points exceeding the modified Z-score threshold of 6 are replaced with the local median. Inspect the result because genuine narrow peaks can also be affected. Raw imported values are retained.

08. Advanced Spectral Deconvolution

For complex research, Instant Raman features a professional Levenberg-Marquardt (LM) non-linear fitting engine. This allows you to resolve overlapping bands that are otherwise impossible to quantify.

Supported Profiles

  • Lorentzian: Standard for crystalline materials (e.g., Silicon, Diamond).
  • Gaussian: Optimized for disordered materials or glasses.
  • Pseudo-Voigt (4-Param): A weighted mixture of Lorentzian and Gaussian profiles; this is a pseudo-Voigt approximation.

Professional Visualization

The deconvolution view provides a stacked vertical layout with a zero-centered residual plot. This allows you to visually verify the "goodness-of-fit" and detect hidden spectral features through residual analysis.

09. Peak Metrology

Center positions are estimated with parabolic interpolation using each local maximum and its two neighbours. FWHM is estimated from the half-maximum crossings. These are estimates, not a guarantee of accuracy. Overlapping bands, noise, irregular sampling, and fitting choices can affect results; inspect fitted curves and residuals.

Saved analysis protocols

Use Import analysis protocol to load an .irp or .json protocol. New protocols record the source file, worksheet, column and row choices, units, conversion settings, and a hash of the selected spectrum. A matching workbook alone is insufficient: the selected spectrum must also match before settings are applied.

Manual baseline anchors, moving-average smoothing, and negative-value clipping are included in new exports. Older protocols without a selected-spectrum hash remain readable for manual review; automatic application is disabled. Keep the original CSV or Excel file. Import details remain available beside each spectrum in the Spectra list.
